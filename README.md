Este repositório contém a resolução das 10 questões referentes ao **Relatório 03**, com foco no uso de estruturas de repetição (`ciclos while`). Os exercícios aplicam conceitos lógicos e matemáticos à resolução de problemas voltados para a área de economia.

- Dominar a sintaxe e a lógica de funcionamento da estrutura `while`.
